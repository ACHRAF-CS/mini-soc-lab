# mini-soc-lab

Learning lab for Windows monitoring and incident investigation with Wazuh, MISP and TheHive.

\## Project status



In progress. Deployment and integrations are not yet implemented.



\## Objectives



\- Collect selected security events from a Windows endpoint using a Wazuh agent.

\- Detect suspicious activity with Wazuh.

\- Enrich selected alerts with indicator context from MISP.

\- Organize investigations and document findings in TheHive.

\- Document setup decisions, tests, troubleshooting, and resource usage.



\## Planned environment



\- Windows laptop with 8 GB RAM.

\- Docker Desktop using the WSL 2 backend.

\- Wazuh, MISP, and TheHive deployed progressively in containers.

\- Wazuh agent installed directly on Windows.



Running the complete stack simultaneously remains to be tested.
